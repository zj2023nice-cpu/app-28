# 🧟 Plants vs. Zombies: Premium Evolution

一个基于 **Phaser 3** 和 **Vite** 构建的高品质“植物大战僵尸”复刻版。本作不仅完美还原了经典的核心玩法，还通过现代化的视觉设计和底层逻辑重构，带来了更稳定、更丝滑的游戏体验。

---

## ✨ 核心特性

-   **💎 Premium 视觉设计**：采用了现代化的“毛玻璃”（Glassmorphism）UI 风格，配合深色花园背景，营造出高端的视觉感官。
-   **🛠️ 逻辑重构**：采用“坐标驱动状态机”逻辑替代不稳定的物理碰撞，彻底告别僵尸“穿透”或“推着植物走”的历史 Bug。
-   **🌈 粒子特效系统**：
    -   子弹击中时带有生动的“汁液”溅射效果。
    -   收集阳光时的金色粒子轨迹。
    -   僵尸死亡时的爆裂尘埃。
*   **📏 全屏沉浸体验**：自动适配 1200x950 的超清分辨率，拥有 **7 行 x 10 列** 的开阔草坪航道。
*   **🎨 矢量程序图形**：所有游戏资源（植物、僵尸、子弹）均通过代码程序化绘制，运行极度轻便且不失精细度。

---

## 🌻 游戏玩法

### 植物图鉴
-   **🌻 向日葵 (Sunflower)**：生产阳光的源泉。每 12 秒产生一次阳光。
-   **🔫 豌豆射手 (Peashooter)**：自动执行远程射击，每 2 秒发射一颗豌豆。
-   **🛡️ 坚果墙 (Wall-nut)**：拥有 **4000 HP** 的超级防御，是阻挡僵尸大军不可逾越的屏障。

### 胜利目标
-   坚持抵挡指定波次的僵尸进攻，清除屏幕上所有敌人即可获胜。
-   **注意**：一旦僵尸踏入左侧的防御边界，脑子就会被吃掉，游戏结束！

## 🚀 开发者指南

### 环境准备
确保你已安装 Node.js (建议 v18+)。

### 启动项目
```bash
# 1. 进入项目目录
cd 244

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

### 核心技术栈
-   **引擎**：Phaser 3.60+
-   **构建工具**：Vite
-   **语言**：Vanilla JavaScript (ES6+)
-   **物理**：Arcade Physics (辅助) + Coordinate State Engine (核心逻辑)

---

## 🛠️ 技术亮点实现

1.  **精准阻挡算法**：通过实时计算僵尸与植物的 X 轴距离和行号匹配，实现像素级的阻挡判定，解决了传统物理引擎常见的挤压穿模问题。
2.  **高性能更新系统**：植物的生产和射击逻辑采用自研的 `customUpdate` 机制，最大化了多对多碰撞检测时的 CPU 性能负载均衡。
3.  **动态 UI 交互**：UIScene 独立渲染，支持跨场景 Registry 数据同步，确保阳光数值、卡片高亮与游戏逻辑实时联动。
